## 太陽能監控系統

這是一個太陽能效能轉換的監控系統，主要透過`PHP`和`MySQL`資料庫進行連接撈取資料顯示於畫面，
在登入頁面加入了`google`機器人驗證方式防止機器人並有權限設定何種身份才可查看該內容，
另外也能將資料導出成`csv file`當作報表，所有資料都會是即時訊息。
